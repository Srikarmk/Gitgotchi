A pet for your git repo

Your terminal is haunted now.

AI agents write a lot of the commits these days. GitGotchi is the little spirit that lives in your repo and watches them land. Every commit feeds it, clean ones grow an Angel, chaotic ones a Demon, and if the agents write most of your code it turns into a Poltergeist.

$pip install gitgotchi
$gitgotchi demo

Python 3.10+ and git. demo runs in a throwaway repo, so you can watch a pumpkin grow into a Poltergeist in about thirty seconds.

Seven forms, all real 3D

Each form is a 3D model built from signed distance fields, raymarched with numpy and cel-shaded into pixel art. In the terminal it's drawn with true-color half blocks, so it bobs, blinks and spins in practically any modern terminal.

It knows who wrote the commit

GitGotchi reads Co-Authored-By trailers, "Generated with" footers and bot accounts. Agent commits still feed your companion, and they also fill its possession meter.

It matches agent addresses and bot accounts, never bare names, so a teammate called Claude or a co-author at an AI lab counts as a human. When an agent runs git commit without a terminal, the hook prints one line so it doesn't flood the agent's context. 

commit 4f9c2e1
Author: You <you@example.com>

    feat: hang a haunted lantern on the porch

    Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>

Pumpkin felt a chill. Claude wrote this one

Live next to your agent

Keep haunt open in a split beside the terminal where you or your agent are working.

gitgotchi install
Adds the post-commit hook. Your other hooks are kept.
gitgotchi adopt
Raises your companion on the history you already have. Thousands of commits replay in under a second.
gitgotchi haunt
A live pane that reacts to every commit as it lands. It watches every branch and worktree, and ignores commits that arrive by pull.
gitgotchi seance
Digs up your repo's ghosts: the oldest TODO, the file nobody has opened in ages, commits made between midnight and 4am. Claude tells the story if you set an API key.
gitgotchi-statusline
One line about your companion for Claude Code's status line, tmux or Starship. Runs in about 50 ms and stays quiet outside haunted repos.
gitgotchi card
Saves a 1200×630 card of your companion to share. Add --gif for one that moves.
gitgotchi badge
A README badge with your companion's pixel portrait and form.
gitgotchi config
How much the hook prints after each commit: full, line or off.
gitgotchi doctor
Checks your setup and tells you how to fix anything that's wrong.

Show off your spirit

gitgotchi card draws your companion's form and stats into a PNG, pixel font and all, sized for link previews.

Run it in a repo you've adopted to see what your history grew into, and how much of it the agents wrote.

What it likes to eat

Every commit gets a score, and your companion's quality drifts toward it. Merge commits don't count. Skip a day and it gets hungry; after a week it goes dormant.
